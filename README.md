# Rayan Bashawri Website

This folder is ready for GitHub Pages.

## Upload from a Mac

1. Unzip `Rayan_Bashawri_Website_GitHub_Ready.zip`.
2. Open the extracted folder.
3. Upload the files and the `assets` folder to the root of the GitHub repository.
4. Do not upload the ZIP file itself and do not place the files inside another folder.
5. Confirm that `index.html` appears at the top level of the repository.
6. In GitHub, open **Settings**, then **Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select the branch containing the website, usually `main`, and select `/ (root)`.

The included `CNAME` file points to `rayanbashawri.com`. Keep it only when that custom domain is configured in GitHub Pages and in the domain DNS settings.
